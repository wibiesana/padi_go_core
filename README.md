# Padi Core Engine (Go)

The pure Go, zero-bloat, high-performance core engine for Padi REST API Framework.

## Features
- **Pure Native ActiveRecord & Query Builder** (No external ORM)
- **JWT Authentication & Bcrypt Hashing**
- **In-Memory & Redis L1/L2 Caching**
- **Database Connection Pool (SQLite pure-Go, MySQL, PostgreSQL)**
- **Automatic Migration & Rollback Runner**
- **SSE Realtime Broadcast Hub**
- **Async DB Queue & Workers**
- **Two-Tier (Base & Concrete) Code & API Collection Generator**
- **Field-Level Validation & Standardized Response Format**
